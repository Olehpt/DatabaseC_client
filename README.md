# DatabaseC Desktop

Electron-клиент сервера DatabaseC на `localhost:18080`.

```powershell
npm start
npm test
```

Запустите сервер отдельно. Клиент автоматически загружает список баз при запуске.

- Базы данных: создание, удаление, импорт новой базы, замена из `.bin`, экспорт через системные файловые диалоги.
- Внутри базы: создание, переименование, удаление и открытие таблиц.
- Внутри таблицы: вкладка «Записи» для добавления, изменения, удаления и очистки; вкладка «Структура» для добавления, переименования и удаления колонок.
- Поддерживаются `integer`, `real`, `char`, `string`, `complex`. Для complex действительная и мнимая части вводятся отдельно. Для нулевого char введите `\0`.
- Нажатие на заголовок колонки переключает сортировку: возрастание → убывание → исходный порядок. Она выполняется в памяти клиента без изменения базы и без дополнительных HTTP-запросов. Числа сравниваются численно, строки — по русской локали, complex — по действительной, затем мнимой части.

Действия над отсортированными записями используют серверный `index`. После изменения данные перечитываются, поскольку удаление сдвигает индексы остальных записей. Индекс не является постоянным идентификатором; одновременное изменение таблицы другим клиентом требует обновления списка перед редактированием.

`npm test` проверяет валидацию типов, сортировку и сохранение индексов, действия над отсортированными записями, защиту от запоздавших ответов и бинарную передачу файлов. UI-тесты используют модель DOM без запуска графического окна.
